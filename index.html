ℹ️ How to set folder permissions to "Anyone with the link can edit":

  1. Open your Google Drive folder
  2. Click the Share button in the top right corner
  3. Click Change to anyone with the link
  4. In the dropdown menu on the right, select Editor
  5. Click Done

Note: This application extracts the folder ID without requiring credentials. You need to manually set the folder permissions in Google Drive.
